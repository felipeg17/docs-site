# Installation

You install Pocket Timer with `pipx`. Make sure `pipx` is available on your system first.

## macOS

Run `pipx install pocket-timer`.

## Linux

Run `pipx install pocket-timer`.

## Windows

Run `pipx install pocket-timer`.

## Verify the installation

Run `pocket --version`. If it prints the installed version, the install worked.

Next, [start your first session](getting-started.md).
