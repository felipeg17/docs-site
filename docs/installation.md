# Installation

Pocket Timer installs with pipx on macOS, Linux and Windows. You need pipx on your machine before you start.

## macOS

Run `pipx install pocket-timer`.

## Linux

Run `pipx install pocket-timer`.

## Windows

Run `pipx install pocket-timer`.

## Verify the installation

Run `pocket --version`. If it prints the installed version, the install worked.

Next, follow [Getting started](getting-started.md) to run your first session.
